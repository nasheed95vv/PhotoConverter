# Политика конфиденциальности — Конвертер файлов

**Дата обновления: 28 октября 2026 года**

### 1. Общая информация

Настоящая политика описывает обработку данных при использовании приложения «Конвертер Фото».

Приложение позволяет преобразовывать файлы в поддерживаемые форматы. Оно поддерживает обычную конвертацию отдельных файлов и пакетную конвертацию нескольких файлов одновременно.

### 2. Обработка файлов

Обработка и конвертация выполняются непосредственно на устройстве пользователя, если это предусмотрено используемой функцией. Содержимое файлов не отправляется разработчику на сервер для выполнения локальной конвертации.

Для выбора и сохранения файлов приложение использует системные средства Android и доступ, предоставленный пользователем.

### 3. Реклама и сбор данных

В приложении используется Yandex Mobile Ads SDK для показа рекламы.

В зависимости от версии SDK и его конфигурации рекламный сервис может собирать и обрабатывать технические данные, включая:

- рекламный идентификатор устройства и другие идентификаторы;
- IP-адрес и сведения о сетевом подключении;
- информацию об устройстве и операционной системе;
- сведения о показах и взаимодействиях с рекламой;
- другие технические данные, необходимые для работы рекламного сервиса.

Эти данные могут использоваться для показа рекламы, оценки её эффективности, ограничения повторных показов и предотвращения мошенничества.

Разработчик не использует содержимое файлов для рекламных целей.

### 4. Передача данных третьим лицам

Некоторые технические и рекламные данные могут передаваться компании «Яндекс» и другим участникам рекламной системы в соответствии с работой используемого SDK.

Подробнее об обработке данных рекламными сервисами можно узнать в политике конфиденциальности Яндекса:

https://yandex.com/legal/international_ads_privacy_policy/

### 5. Хранение и защита данных

Разработчик не хранит файлы пользователей на собственных серверах, если они обрабатываются локально на устройстве.

Сроки хранения рекламных данных определяются соответствующими рекламными сервисами. Защита передаваемых данных зависит от используемого SDK и сетевого соединения.

### 6. Удаление данных и настройки рекламы

Приложение не требует создания учётной записи для выполнения конвертации.

Пользователь может управлять рекламным идентификатором и доступными настройками рекламы через настройки Android. Сброс рекламного идентификатора не гарантирует удаление всех данных, ранее обработанных рекламными сервисами. По вопросам удаления таких данных следует обращаться к соответствующему провайдеру.

### 7. Конфиденциальность детей

Приложение не предназначено для намеренного сбора персональных данных детей. По вопросам обработки данных можно обратиться к разработчику.

### 8. Изменения политики

Политика может обновляться при изменении функций приложения, рекламных сервисов или применимых требований. Актуальная версия должна быть доступна по опубликованной ссылке.
